# Dhamodaran M — Cloud & DevOps Portfolio

A responsive, static portfolio built from Dhamodaran's resume. It highlights AWS infrastructure and migration work, CI/CD automation, software projects, internships, education, and training.

## Run locally

From this directory, start any static server. For example:

```sh
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000).

## Included

- Responsive portfolio sections for projects, experience, toolkit, education, and contact
- Mobile navigation, reduced-motion support, and copy-email interaction
- Resume PDF linked from the contact section
- No build step or third-party JavaScript dependencies

## Publish

The site is static and can be hosted with GitHub Pages. In the repository settings, enable Pages from the `main` branch and `/ (root)` folder.
